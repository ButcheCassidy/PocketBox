# Screenshots

Screenshots for the main README go in this folder, as PNG files taken on a Pixel in portrait, ideally once in light and once in dark mode:

| File | Shows |
|---|---|
| `now-playing-light.png`, `now-playing-dark.png` | Now Playing with album art, quality chips and controls |
| `albums.png` | The Albums tab with its shelves |
| `songs.png` | A–Z songs with the letter rail |
| `search.png` | Search results while typing |
| `quality.png` | The audio quality sheet |
| `onboarding-look.png` | Picking a theme with the live preview |
| `widget.png` | The home-screen widget |

To take one: press power and volume down together, then copy the image from the phone's `Pictures/Screenshots` folder. Once they're here, link them from the **Screenshots** section of the README.
